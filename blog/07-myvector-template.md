# int만 담던 MyVector에 레몬을 넣기까지: 템플릿

## 궁금했던 것

지금까지 만든 MyVector는 int만 담을 수 있었다. `std::vector<std::string>`이나 언리얼의 `TArray<T>`처럼 어떤 타입이든 담으려면 어떻게 해야 할까?

## 실험 설계

1. MyVector에 `template <typename T>`를 붙이고 int를 T로 바꾼다.
2. `MyVector<std::string>`에 "lemon"을 넣고 꺼내 본다.

```cpp
MyVector<string> ca;
ca.push_back("lemon");
cout << ca[0] << endl;
```

## 결과

### 첫 시도: 링크 에러

> 이렇게 쓰는 게 아닌가?

```
error LNK2019: "MyVector<int>::MyVector<int>(void)" ... main 함수에서 참조되는 확인할 수 없는 외부 기호
```

함수 본문을 MyVector.cpp에 두었더니, main.cpp에서 `MyVector<int>`를 만들 때 본문을 볼 수 없었다. 템플릿은 쓰는 곳에서 T를 채워 코드를 만들기 때문에 본문이 헤더에 있어야 한다.

> 그러면 분리하는 이유가 사라지는데.

맞다. 템플릿은 한 번만 컴파일하거나 구현을 숨기는 분리의 장점을 가질 수 없다. 그래서 `std::vector`도, `TArray`도 헤더에 본문이 있다. 헤더에 전부 넣었다.

### 두 번째 시도: string 벡터가 안 된다

> 헤더에 전부 구현했는데, 이제 string 벡터를 만들려고 했는데 안 되네.

```
MyVector.h(87): error C2676: 이항 '>=': 'T'이(가) 이 연산자를 정의하지 않거나 ... with [ T=std::string ]
MyVector.h(90): error C2677: 이항 '[': 'T' 형식을 사용하는 전역 연산자가 없거나 ... with [ T=std::string ]
```

int를 전부 T로 바꾸다 보니 `operator[]`의 번호까지 T가 되어 있었다. 문자열 벡터에서 "lemon번째 칸"을 찾으려고 한 셈이다. 번호와 개수는 무엇을 담든 정수다.

> int인 거 같아. 이제 리턴값을 고쳐야 하는 거지?

리턴은 그대로 두는 게 맞았다. 꺼내는 건 계란이니까 `T&`. 바꿀 건 괄호 안의 번호 타입 하나였다.

그다음엔 push_back과 대입 연산자 안에 남아 있던 `new int`를 `new T`로 바꿨다.

> 오 이제 레몬이 나와.

### 검사

```
[int]    a [1, 2, 4, 4, 5], 복사, 대입, 자기 대입, 빈 벡터 대입 후 push → no leaks
[float]  f [1.5, 2.5, 3.5], no leaks
[string] s 5개 (1→2→4→8로 늘어남), 복사, 대입, 자기 대입 → no leaks
```

## 왜 그런가

- 템플릿은 설계도다. `MyVector<int>`, `MyVector<std::string>`은 쓰는 곳에서 T를 채워 넣어 각각 만들어진다. 그래서 본문이 헤더에 있어야 한다.
- 템플릿 함수는 실제로 쓰일 때만 만들어진다. 대입 연산자에 `new int`가 남아 있어도, string 벡터끼리 대입하기 전까지는 에러가 나지 않았다.
- T로 바꿔야 하는 건 담는 것(판, 넣는 값, 꺼내는 값)뿐이다. 계란 수, 칸 수, 칸 번호는 정수다.

## 정리

일단 템플릿화를 시킨다는 게 어디서부터 해야 할지 너무 막막했고, 하고 보니 소스와 헤더 파일 분리가 그냥은 안 된다는 것이 까다롭다고 느꼈다. 그리고 어디는 T로 하고 어디는 원래 타입으로 해야 하는지에 대한 생각을 계속해야 한다는 것을 느꼈다.
